# ASP.NET SellPhone – Used Phone E-commerce Website

A web application for selling used smartphones built with ASP.NET MVC (.NET) and Bootstrap.  
This project focuses on backend architecture, MVC pattern implementation, and API-based data handling.

---

## ⏳ Development Timeline
- **Developed during:** Semester 1 – Year 3  
- **Course Context:** Web Application Development  
- **Architecture:** ASP.NET MVC  
- **Project Type:** Academic Project  

---

## 📌 Project Overview

This project is a used phone e-commerce website developed using C# and ASP.NET MVC.

The system allows users to browse products, view details, and manage purchases.  
An admin dashboard provides statistical summaries and product management features.

The frontend UI is styled using Bootstrap, while backend logic handles routing, database interaction, and API-based data processing.

---

## 🚀 Key Features

### 👤 User Side
- Browse used smartphone listings
- View product details
- Category-based filtering
- Responsive layout using Bootstrap
- Manage delivery address

### 🛠 Admin Dashboard
- Product management and other objects (CRUD operations)
- Statistical dashboard (sales & product stats)

---

## 🏗 Architecture

- ASP.NET MVC pattern
- Controllers handle routing and business logic
- Models manage data structure and database interaction
- Views render UI using Razor syntax
- API endpoints used for asynchronous data updates
